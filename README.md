# Новицкая Елизавета Web-программирование 3.2 Лабораторная 2

Сайт по планированию задач - https://lezyonish.github.io/WEB3.2-Novitskaya-Elizaveta-2-lab/
Позволяет создавать задачи с датой выполнения, редактировать их, отмечать выполненными и управлять порядком отображения.

## Технологии

- HTML5 - структура документа.

- CSS3 - оформление.

- JavaScript - создание интерфейса и обработка действий.

- DOM API - создание HTML-элементов.

- localStorage - хранение задач в браузере.

- HTML Drag and Drop API - перетаскивание задач.
